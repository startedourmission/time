# 시간 관리 시스템

> 시간의 안정적인 흐름을 보장하기 위한 이슈 트래킹 플랫폼입니다.

## 개요

본 시스템은 시간의 비정상적 동작을 체계적으로 수집, 분류, 관리합니다.
수집된 데이터는 담당팀에 전달되며 면밀히 검토됩니다.

## 지원하는 이슈 유형

| 유형 | 설명 |
|------|------|
| `time-too-slow` | 시간이 비정상적으로 느리게 흐르는 경우 |
| `time-too-fast` | 시간이 비정상적으로 빠르게 흐르는 경우 |
| `time-skipped` | 특정 구간의 시간이 소실된 경우 |

## 이슈 제보

상단의 **Issues** 탭에서 양식에 맞게 제보해 주세요.  
모든 제보는 담당팀에서 검토합니다.

## SLA

- 응답 시간: 최대한 빠르게
- 해결 시간: 미정
- 패치 배포 일정: 미정
